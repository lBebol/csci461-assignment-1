# CSCI461 Assignment 1 — Dockerized YouTube Spam Analysis

Nile University · Introduction to Big Data · Fall 2026

Public project repository: https://github.com/lBebol/csci461-assignment-1

This project uses approved dataset **3, UCI YouTube Spam Collection**, to study
spam/ham comments, sampling, text features, supervised classification, and K-Means.
The complete analysis runs in the assignment's required Jupyter Docker image.

The initial scaffold contains an empty notebook and the dataset on the host,
before the first custom-image build. The completed notebook, measured results,
and full reproduction instructions are added in subsequent commits.

Dataset attribution and download instructions: [data/README.md](data/README.md).
